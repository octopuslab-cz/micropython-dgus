Installation
============

``micropython-dgus`` is intended for MicroPython projects using DWIN DGUS UART TFT
displays.

Source Checkout
---------------

Copy the ``dgus`` package into your MicroPython project or upload it to the
target board with your preferred tool, for example::

   mpremote cp -r dgus :

Documentation Build
-------------------

Build these docs from the ``docs`` directory::

   make html
